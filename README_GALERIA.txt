COMO AGREGAR TUS FOTOS A LA GALERIA DE COMPUTEK

1. Abre la carpeta "galeria".
2. Coloca tus fotos dentro de esa carpeta.
3. Nombra las fotos exactamente así:
   foto1.jpg
   foto2.jpg
   foto3.jpg
   foto4.jpg
   foto5.jpg
   foto6.jpg
4. Abre index.html en el navegador y entra a "Galería".

Puedes usar JPG, PNG o WEBP. Si usas otro formato, cambia también la extensión en index.html.

Para tener más fotos, copia una tarjeta <article class="galeria-item"> en index.html y cambia el nombre de la imagen.
